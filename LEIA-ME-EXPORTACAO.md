# Projeto Originalli — cópia para desenvolvimento

> Documento original da exportação GPT Work, preservado como referência histórica. Para executar e editar a estrutura atual, siga o [README.md](README.md).

Esta pasta contém o código-fonte da versão publicada do novo site da Originalli, incluindo:

- páginas institucionais;
- portal de Vida em Grupo;
- estilos, scripts e imagens;
- código do servidor;
- estrutura e migrações do banco de dados;
- testes automatizados;
- arquivos de configuração do projeto.

## Abrir no VS Code

1. Descompacte o arquivo ZIP.
2. No VS Code, escolha **Arquivo > Abrir Pasta**.
3. Selecione a pasta `originalli-novo`.
4. Abra o terminal integrado.
5. Execute `npm install`.
6. Para validar o projeto, execute `npm test`.
7. Para gerar a versão de publicação, execute `npm run build`.

## Importante

Esta exportação não contém senhas, credenciais temporárias, sessões de usuários nem os arquivos sigilosos armazenados no ambiente hospedado. O banco de dados e os arquivos enviados ao portal permanecem protegidos no serviço de hospedagem.

O histórico interno do repositório (`.git`) e arquivos temporários de publicação também não foram incluídos.
