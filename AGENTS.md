# Projeto Originalli

Leia `README.md` e `docs/CONTEXTO.md` antes de retomar o trabalho.

- A raiz do projeto é esta pasta. Fontes do site ficam em `public/`; servidor em `server/`; portal em `portal/`.
- Nunca versione credenciais, `.env`, banco de dados, documentos privados, backups ou dados de clientes.
- `.env.example` deve conter somente exemplos sem segredos.
- Atualize `docs/CONTEXTO.md` quando mudar a arquitetura ou concluir uma etapa relevante.
- Use os comandos e requisitos do README para executar e validar o projeto.
- O gerador de páginas sobrescreve páginas internas: consulte o README antes de executá-lo.
- GitHub guarda o código e a documentação. Dados de produção precisam de infraestrutura separada.
